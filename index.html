Firebase Database URL
📋 Firebase 무료 설정 방법 (5분)
  1. console.firebase.google.com 접속 → 구글 로그인
  2. 프로젝트 추가 클릭 → 이름 입력 → 계속
  3. 좌측 메뉴 빌드 → Realtime Database → 데이터베이스 만들기
  4. 위치: asia-southeast1 선택 → 테스트 모드로 시작
  5. 생성된 URL 복사 (예: https://xxx-default-rtdb.asia-southeast1.firebasedatabase.app)
  6. 위 입력창에 붙여넣고 연결 클릭
✅ 무료 플랜 기준 1GB 저장 / 10GB 전송 — 팀 대시보드로 수년간 충분합니다.
